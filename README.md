## ⚙️ How It Works

1. User enters query (e.g., "total revenue")
2. Backend converts it into SQL
3. SQL query is executed on database
4. Result is returned and displayed

## 🛠️ Run Locally

### 1. Clone repo

```bash
git clone https://github.com/your-username/ai-sql-assistant.git
cd ai-sql-assistant
```

### 2. Setup environment

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run backend

```bash
uvicorn app.main:app --reload
```

### 5. Open frontend

Open `index.html` in browser
