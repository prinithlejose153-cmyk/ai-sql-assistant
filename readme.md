# AI SQL Assistant 🚀

A FastAPI-based backend that converts natural language queries into SQL and executes them on a database.

## 🔥 Features

* Natural Language → SQL conversion
* SQLite database integration
* FastAPI backend
* AI-powered query understanding (Gemini API)
* Swagger UI testing

## 🛠 Tech Stack

* Python
* FastAPI
* SQLite
* Google Gemini API
* Uvicorn

## ⚙️ Setup

```bash
git clone <your-repo-link>
cd AI-SQL-Assistant

python -m venv .venv
.venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

## ▶️ Run Server

```bash
uvicorn app.main:app --reload
```

## 🌐 API Endpoint

Open in browser:

```
http://127.0.0.1:8000/docs
```
